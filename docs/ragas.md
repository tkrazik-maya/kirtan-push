# Raga Reference

Quick reference for the ragas used in this set. Each entry has the scale degrees, Push setting, and which kirtans use it.

## Kafi (minor)

Scale: 1, 2, b3, 4, 5, b6, b7
Push: Minor
Kirtans: Ram Ram, Sri Ram Jai Ram, Hare Krishna, Jai Ma, most general bhakti

## Bhairavi

Scale: 1, b2, b3, 4, 5, b6, b7
Push: Phrygian (close approximation)
Better: M4L custom scale — C, Db, Eb, F, G, Ab, Bb
Kirtans: Om Namah Shivaya, many Neem Karoli recordings
Notes: The b2 is the characteristic note. Phrygian on Push gets you there for improvisation; use M4L custom for strict raga work.

## Bilawal (major)

Scale: 1, 2, 3, 4, 5, 6, 7
Push: Major
Kirtans: Some morning kirtans, Hari Om variations
Notes: Bright and open. Less common in Neem Karoli lineage but useful.

## Common roots by kirtan

| Kirtan | Common root | Raga |
|--------|-------------|------|
| Ram Ram Ram | D | Kafi |
| Sri Ram Jai Ram | D or C | Kafi |
| Om Namah Shivaya | D | Bhairavi |
| Hare Krishna Hare Rama | G | Kafi |
| Jai Ma Durga | C | Kafi |
| Om Namo Bhagavate | G | Kafi |

Roots are conventional starting points — transpose freely to match your voice.
