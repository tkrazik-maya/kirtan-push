# kirtan-push

Solo kirtan performance rig for Ableton Push 2.0. Sample-based traditional Indian instruments (tanpura, harmonium, tabla, kartals) arranged for one-person live kirtan performance in the Neem Karoli / Ram Dass lineage.

## What lives here
- `set/` — Ableton Live sets (.als files)
- `racks/` — Ableton Instrument Rack and Drum Rack presets (.adv, .adg)
- `samples/` — Audio samples (gitignored; see `samples/README.md` for sourcing)
- `docs/` — System design, raga charts, performance notes, sample sourcing

## Key context
- Push 2.0 requires Ableton Live (not standalone)
- Style: Neem Karoli / Ram Dass lineage - minimal, meditative, mantra-repetition arc
- Sound engine: sample-based traditional (tanpura, harmonium, tabla, kartals)
- Performance model: tabla/tanpura run as looping clips; harmonium played live over the top
