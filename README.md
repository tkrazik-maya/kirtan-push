# kirtan-push

Solo kirtan performance rig for Ableton Push 2.0.

One person. Traditional Indian instruments (tanpura, harmonium, tabla, kartals). Neem Karoli / Ram Dass lineage — minimal, meditative, mantra-driven.

## How it works

Tabla and tanpura run as looping clips triggered from the Push. Harmonium is played live over the top in scale-locked melodic mode. The session is organized by energy arc: opening, call/response, building, climax, wind-down, closing.
